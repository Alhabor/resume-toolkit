# 批注与迭代

每条批注先判断它属于哪一层：

1. **事实层**：日期、数字、职责、工具、结果或其他经历事实；
2. **内容层**：措辞、取舍、顺序、岗位定制或中英文表达；
3. **格式层**：字体、颜色、间距、对齐、页数、二维码和打印布局。

处理顺序：

1. 定位批注对应的原文和证据；
2. 如果批注改变事实，先更新证据台账并确认冲突；
3. 修改相应的 JSON 或 Typst 模板；
4. 重新生成中英文 PDF/PNG；
5. 检查文字提取、页数和视觉布局；
6. 在交付说明中写清修改了哪一层。

不要直接编辑 PDF。不要因为批注中的一个视觉建议，未经确认就改变其他
经历、日期或数字。
